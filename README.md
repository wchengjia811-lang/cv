# 吴澄嘉 Chester · 个人作品集

福建商学院，国际经济与贸易，2027 届。

这是可直接部署到 GitHub Pages 的静态网站，使用 HTML、CSS 和浏览器 JavaScript，无需安装依赖或构建。

## 发布

1. 在 wchengjia811-lang 账号下新建公开仓库 cv，并勾选添加 README。
2. 将本目录内容上传到仓库根目录，确保 index.html、portfolio.css 与 assets 在同一级。文件夹 cv 本身不需要上传。
3. 打开仓库 Settings → Pages。
4. Source 选择 Deploy from a branch，分支选择 main，目录选择 /(root)，保存。
5. 等待 GitHub 页面显示发布成功，并点击 Visit site。预计地址为 https://wchengjia811-lang.github.io/cv/ ，未发布前该地址不保证可访问。

所有站内资源均使用相对路径，支持 /cv/ 子路径。根目录 .nojekyll 用于按静态文件发布。该站包含公开展示的姓名、邮箱和简历照片。
